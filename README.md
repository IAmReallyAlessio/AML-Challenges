This repository contains the challenges for the AML course at EURECOM. We tackled 3 different challenges:
- **Aerial Cactus Classification**: we classified aerial cactus images from a low-resolution dataset using various ML models, including CNNs, and experimenting with VQA-based labeling.
- **Anomalous Sound Detection**: we developed ML models to detect anomalous sounds in industrial machines, given a dataset that contains only normal sound samples, using various ML models.
- **Sentiment Analysis on Tweets**: we classified tweets with a positive, negative or neutral label, reflecting the sentiment of the user writing the tweet, experimenting with transformer-based models and identifying the words which are most responsible for the predicted sentiment.
